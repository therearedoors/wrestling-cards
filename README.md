# Wrestling Cards

A web app for playing **Raw Deal** — the classic WWE trading card game — with solo (goldfish) practice and real-time multiplayer.

**Live Demo**: www.wrestling-cards.com

## Features
- **Solo Practice**: Goldfish mode to test decks and learn mechanics.
- **Multiplayer**: Real-time matches via Socket.io.
- **Deck Builder**: Build and save decks for Premiere Edition.
- **Rules Engine**: Faithful implementation of Raw Deal Premiere (first set).
- Playable in browser, no downloads needed.

Inspired by platforms like Jinteki.net for Netrunner—functional first, expansions later.
